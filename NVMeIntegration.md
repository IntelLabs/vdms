## Setup SPDK with File Direct Bdev on Target
This should be done on the machine where the data store is located. We term this as the 'Target'.

### Setup the dependencies

```
# Get boost
wget https://archives.boost.io/release/1.87.0/source/boost_1_87_0.tar.gz
tar -zxvf boost_1_87_0.tar.gz

# Install libtbb
sudo apt install libtbb-dev

# Install the ots_fs_extents dependency
mkdir ~/ots_file_built_deps
cp -r boost_1_87_0/boost/ ots_file_built_deps/
git clone https://github.com/intel-sandbox/araghuna1.ots_fs_extents
cd araghuna1.ots_fs_extents
make

# The dependency files will be stored in "ots_file_built_deps". Any other directory can be used. Modify the "Makefile" to update the same. The "boost" directory should also be copied in the same directory.
```

### Build SPDK
```
git clone https://github.com/intel-sandbox/araghuna1.ots_spdk.git
cd araghuna1.ots_spdk
git checkout ⁠ots-file-direct
./configure --with-ots-file=~/ots_file_built_deps/ # This is the directory where the dependencies were stored.
make 
```

### Update the start_target.sh file
Modify the following variables in the start_target.sh file.
```
ipaddrserver=10.23.221.241               # IP Address of the Target
app_port=4421                            # Port to be used for NVMe Connections
nqnname="nqn.2024-02.io.spdk:cnode1"     # Namespace used by the connections
aioname="nvme2_bdev"                     # AIO Bdev name
fdname="fdtest"                          # File-direct Bdev name
device="/dev/nvme2n1"                    # Use lsblk to get the device name
```

### Setup the Target
```
sudo HUGEMEM=32768 PCI_ALLOWED="none" ./scripts/setup.sh #Set the HUGEMEM as per your needs
sudo nohup ./build/bin/nvmf_tgt --wait-for-rpc & sleep 2
sh start_target.sh
```

## Setup VDMS

### VDMS and Target on Same Machine
- Build VDMS
- Mount the NVMe drive on the filesystem
```
sudo mount /dev/nvme2n1 /mnt/nvmedrive
```
- Modify the VDMS config file to have the `db` and `tmp` directory on the NVMe drive.
```
"db_root_path": "/mnt/nvmedrive/db",
"tmp_path": "/mnt/nvmedrive/tmp",
```

### VDMS and Target on Different Machines
- Build VDMS
- Mount the NVMe drive over TCP on the filesystem
```
sudo nvme connect -t tcp -n <nqnname> -a <ipaddrserver> -s <app_port>
lsblk # Gets the connected NVMe drive name, say /dev/nvme2n1
sudo mount /dev/nvme2n1 /mnt/nvmedrive
```
- Modify the VDMS config file to have the `db` and `tmp` directory on the NVMe drive.
```
"db_root_path": "/mnt/nvmedrive/db",
"tmp_path": "/mnt/nvmedrive/tmp",
```

## Build the pyspdk Library on the Initiator
The Initiator is the system that will connect to the Target and read files over NVMe.

### Setup the dependencies

```
# Get boost
wget https://archives.boost.io/release/1.87.0/source/boost_1_87_0.tar.gz
tar -zxvf boost_1_87_0.tar.gz

# Install libtbb
sudo apt install libtbb-dev

# Install the ots_fs_extents dependency
mkdir ~/ots_file_built_deps
cp -r boost_1_87_0/boost/ ots_file_built_deps/
git clone https://github.com/intel-sandbox/araghuna1.ots_fs_extents
cd araghuna1.ots_fs_extents
make

# The dependency files will be stored in "ots_file_built_deps". Any other directory can be used. Modify the "Makefile" to update the same. The "boost" directory should also be copied in the same directory.
```

### Build the pyspdk Library
```
# Clone the github repo
git clone https://github.com/intel-sandbox/pyspdk.git
cd pyspdk

# Copy necessary depency files for easy access
cp -r ~/ots_file_built_deps .

# Update the submodules
git submodule update --init --recursive

# Change to the spdk subdirectory
cd ots_spdk

# Change to the file-direct branch
git checkout ots-file-direct

# Install SPDK dependencies
./scripts/pkgdep.sh

# Configure spdk
./configure --with-shared --without-fuse --without-nvme-cuse --with-ots-file=../ots_file_built_deps

# Build spdk
make

# Copy spdk.map file which creates a mapping between spdk and the python library 
cp ../spdk.map shared_lib/

# Setup SPDK on the system
sudo HUGEMEM=<SIZE> PCI_ALLOWED="none" ./scripts/setup.sh #Set the HUGEMEM as per your needs

# Change back to the pyspdk library
cd ..

# Install python dependencies
python3 -m pip install -r requirements.txt

# Build the pyspdk library
make
```

## Setup the Remote UDF Server
- Copy the `remote_function` and `resources` directory from the VDMS repo on the Initiator. Both folders should be in the same parent directory.
- Copy the `pyspdk.so` file, generated by `pyspdk` in the `remote_function` directory.
- Run `udf_server.py` with superuser privileges
